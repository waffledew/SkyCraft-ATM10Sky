SKYCRAFT ATM10SKY - FRIEND SETUP
================================

Minecraft stays hidden during normal gameplay. Skyrim is the game window you use.
Prism may appear only for the first Microsoft sign-in or when an error needs attention.

Before installing:
1. Own Skyrim SE/AE and Minecraft Java Edition.
2. Install SKSE64 and Address Library for your Skyrim version.
3. Install normal SkyCraft with Vortex and launch it once to finish Microsoft sign-in.
4. Install ATM10 To the Sky 2.0.6 in CurseForge.

Then:
1. Add SkyCraft-ATM10Sky-Vortex-Patch.zip to Vortex and let it overwrite SkyCraft.
2. Double-click INSTALL-ATM10SKY.cmd in this folder.
3. Paste the host's e4mc.link address when asked. The host enters localhost:25565.
4. Start Skyrim through SKSE.

The first ATM10Sky load can take several minutes. Click SKSE only once and wait.
Do not separately launch CurseForge, Prism, or another Minecraft copy.
Stay on Skyrim's main menu while the SkyCraft loading panel advances. Load your
save only after it says "100% - Minecraft ready". The percentage represents real
startup stages, so it may remain at one number for a while during the large mod load.

HOST: The dedicated server is optional for solo play. If localhost is offline, SkyCraft
tries it once and then opens your normal local mirror world. Start the server before
SKSE whenever you want shared multiplayer progress.

When the host restarts the server, its e4mc.link address normally changes. Double-click
CHANGE-SERVER-ADDRESS.cmd, paste the new address, and then start Skyrim through SKSE.

HOST ONLY:
After Prepare-Server.ps1 finishes, double-click START-SKYCRAFT-SERVER.cmd inside the
prepared server folder. Wait for "Done" and "Domain assigned", then send friends the
displayed e4mc.link address. The address is also saved in SERVER-ADDRESS.txt beside
the launcher. Type stop in that server window before closing it.

The host uses localhost:25565 and does not paste the public address. Friends should
treat the e4mc address like an invite link and avoid posting it publicly unless the
host intends to run a public server.

If Windows asks what should open the .cmd file, choose Windows Command Processor.
The .ps1 files are underlying advanced scripts; friends normally do not need to open them.

For troubleshooting and server setup, read README.md.

ALREADY INSTALLED? Close Skyrim and Minecraft, install this release's Vortex
patch, and run UPDATE-ATM10SKY.cmd instead of reinstalling the full profile.
Your saves, settings, and server address are kept. The updater sets NeoForge
21.1.250 and installs the matching SkyCraft bridge. The host must also update
the stopped server. Launch through SKSE, using the generated Prism profile.
Character sync is included in the SkyCraft jar; no separate download is needed.
